# TinderUD · Memoria

Lee `docs/memory/README.md` y los archivos pertinentes. Registra decisiones confirmadas en `decisions.md`, problemas y divergencias en `known-issues.md` y tareas abiertas en `backlog.md`, dentro de `docs/memory/`. Incluye fecha, contexto y referencias verificables en cada entrada.

Crea un archivo propio por entrega en `docs/memory/handoffs/`. Resume alcance, cambios, verificaciones y pendientes. Coordina con el responsable antes de editar una entrada compartida si hay solapamiento.

Excluye secretos, tokens, contraseñas, datos personales y contenido sensible. Enlaza archivos o commits en vez de copiar registros de sesión.
