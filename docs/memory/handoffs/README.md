# Entregas entre agentes

Crea un Markdown por entrega, por ejemplo `AAAA-MM-DD-tarea.md`. Incluye fecha, contexto y alcance asignado, cambios, verificaciones, bloqueos o pasos pendientes, y referencias a archivos o commits. Si hay varias entregas de una tarea el mismo día, añade un sufijo descriptivo.

Consulta las [reglas de memoria](../README.md) antes de guardar la entrega.
