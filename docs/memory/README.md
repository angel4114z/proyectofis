# Memoria compartida de TinderUD

Consulta [decisiones](decisions.md), [problemas conocidos](known-issues.md), [pendientes](backlog.md) y [entregas](handoffs/README.md) según la tarea.

Usa un encabezado con fecha `AAAA-MM-DD` y un título breve por entrada. Incluye contexto, decisión, solución o próximo paso y referencias a archivos, commits o tareas. Actualiza una entrada existente al resolverla. Las decisiones abiertas pertenecen al backlog hasta su confirmación.

Excluye secretos, tokens, contraseñas, datos personales, valores de entorno, transcripciones y contenido sensible. Usa rutas relativas al repositorio y resume los errores sin copiar registros de sesión.
